# User Stories

15 stories across 3 roles.

## Developer

1. Register and log in.
2. Submit Python code (paste or upload).
3. See findings from Semgrep and LLM side-by-side.
4. Toggle plain-language explanations on/off (thesis variable).
5. See analysis history.
6. Export an analysis as structured data.

## Security Auditor

7. View analyses submitted by assigned developers.
8. Mark a finding as confirmed / false positive / accepted risk.
9. Add comments to findings (separate from verdict).
10. Dashboard view of recent analyses across assigned developers.

## Admin

11. Create, disable, assign roles to user accounts.
12. View system usage and error logs.
13. Configure LLM provider and prompt template (thesis enabler — prompt versioning).

## Cross-cutting

14. System handles malicious/broken code safely.
15. System returns clear error messages.
