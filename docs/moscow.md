Auth, RBAC, code submission (paste + upload), Semgrep, LLM via LangChain, side-by-side comparison, explanation toggle, basic history, audit trail, safe code handling, error handling.

Auditor functionality, admin user management, password reset, JSON export, history filters.

Auditor comments, profile editing, admin LLM config UI, CSV export, code search, admin log UI.

## Won't-Have-This-Time

Email notifications, PDF export, GitHub integration, multi-language, GDPR account deletion.
